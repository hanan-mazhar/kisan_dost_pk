# 🌾 Kisan Dost PK – Smart Agriculture Marketplace

## 📖 Case Study

### Overview

Kisan Dost PK is a Flutter-based agriculture marketplace that connects farmers, buyers, transporters, and administrators on a single platform. The application simplifies the process of selling agricultural products, purchasing fresh produce, managing logistics, and monitoring market prices.

The project was developed with a focus on improving communication between stakeholders while providing a modern, user-friendly mobile experience.

---

# 🎯 Problem

Farmers often struggle to find direct buyers, access up-to-date market prices, and arrange reliable transportation for their products. Buyers also face challenges in sourcing quality produce from trusted farmers.

The objective of this project was to create a digital platform that streamlines agricultural trading and logistics.

---

# 💡 Solution

Kisan Dost PK provides a centralized platform where:

* Farmers can list agricultural products.
* Buyers can browse and purchase products.
* Transporters can manage deliveries.
* Administrators can monitor the entire system.
* Users can view daily mandi (market) rates.
